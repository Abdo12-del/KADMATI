# أوروفا ستوديو — منصة تصميم عروض تقديمية

منصة تصميم عروض في المتصفح: سهولة أدوات التصاميم الجاهزة، قوة PowerPoint في العرض والتصدير،
مرونة أدوات التصميم الاحترافية في التحكم بكل عنصر، وAI يعمل **داخل** الواجهة ويخرج عناصر قابلة للتحرير.
العربية فيها من الدرجة الأولى (RTL حقيقي، خطوط، تشطيب، أرقام) مع EN/FR، والتصدير إلى PPTX **قابل للتحرير** فعلًا.

```bash
npm install        # الحزم مثبتة في package.json
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit (الملزمة تمر نظيفة)
npm run build      # حزمة ثابتة في dist/
```

> البناء محلي بالكامل: لا مفتاح API ولا خادم مطلوب. الحفظ في IndexedDB، والتصدير والاستيراد
> يحدثان في المتصفح. الذكاء الاصطناعي (اختياري): الإعدادات ← الذكاء الاصطناعي — اختر المصدر:
> **Aurova Model** (نموذجنا، عبر خادم Aurova بلا مفتاح — انظر `docs/AUROVA_MODEL.md`)، أو OpenAI /
> Anthropic / Gemini / Mistral / Groq / DeepSeek / OpenRouter بمفتاحك، أو أي خادم متوافق مع OpenAI؛
> بدون أي منها يعمل المخطّط المحلي الحتمي.

## ماذا يوجد فعليًا

- **الهبوط** — عنوان «صمّم عروضًا تقديمية تستحق أن تُعرض.»، معاينة تفاعلية للشرائح، أمثلة بالفئات، ودخول مباشر للمحرر/القوالب.
- **المكتبة** — الرئيسية / عروضك / القوالب / العلامة التجارية / العناصر / سلة المحذوفات. بحث، فرز، مجلدات
  (إنشاء/تسمية/حذف/نقل عرض إليها)، مفضّلة، وسلة باستعادة. الصور المصغّرة **مبنية من المستند** لا لقطات مخزّنة.
- **عرض جديد** — فارغ / من قالب / استيراد PPTX / توليد بالـ AI (عدد الشرائح، نوع العرض، الجمهور، الأسلوب البصري).
- **المحرر** — مصغّرات يسارًا (سحب لإعادة الترتيب، نسخ/حذف/إخفاء)، لوحة وسطى، مفتّش يمينًا، شريط أدوات أعلى،
  حالة/تكبير/عرض أسفل. عناصر: نص، صورة، شكل، خط، أيقونة، SVG، جدول، مخطط، فيديو، مجموعة، إطار.
  تحريك/تغيير حجم/تدوير/تكرار/حذف/ترتيب طبقات/محاذاة/توزيع/مجموعة.
- **سحب وإفلات احترافي** — شبكة، خطوط محاذاة ذكية، التصاق بحواف العناصر الأخرى، توزيع متساوٍ، Alt-سحب للتكرار.
- **نص احترافي** — خط/حجم/وزن/ميل/تسطير/لون/تظليل/تباعد حروف وسطور/محاذاة/قوائم/روابط و RTL↔LTR لكل فقرة.
- **صور** — رفع، سحب وإفلات، قصّ، قناع، تدوير زوايا، فلاتر، شفافية؛ الأصول مشتركة بين الشرائح.
- **قوالب حقيقية** — 12 قالبًا عربيًا (أعمال/تعليم/تسويق/ستارت أب/معرض/أكاديمي/تقرير…) بثيم وخطوط وألوان
  وتخطيطات ومكوّنات، لا «خلفية جميلة». مكتبة 16 تخطيطًا مع تبديل غير مُتلف للمحتوى.
- **علامة تجارية داخل التطبيق** — شعار، لوحة، خطوط، ثم تطبيقها على العرض كاملًا بضغطة (وإرجاعها بالتراجع).
- **AI** — تحسين/اختصار/رسمي/اقتراح عنوان لكل عنصر، توزيع الشريحة وموازنة النص، مراجعة العرض كاملًا
  (تباين، هرمية، كثافة، عناصر خارج الشريحة، اتساق الخطوط) مع «إصلاح» لكل ملاحظة.
- **حركات وانتقالات** — Fade/Appear/Slide/Zoom/Scale مع مدة وتأخير واتجاه، وانتقالات الشريحة None/Fade/Slide/Push/Zoom،
  تُعرض في نمط العرض وتُصدَّر حيث يدعمها PPTX.
- **نمط العرض** — ملء الشاشة، تنقّل بالفأرة/لوحة المفاتيح، مؤقّت، ملاحظات المتحدث، شريط تقدّم.
- **تصدير** — PPTX قابل للتحرير، PDF، PNG، JPG (2×). **استيراد** PPTX إلى نص/صور/أشكال/جداول/مخططات/خلفيات.
- **حفظ تلقائي** — Saved / Saving… / Offline، وصمود التحديث (F5). تراجع/إعادة قويان لكل العمليات (حتى 150 خطوة).

## العروض التجريبية (محتوى حقيقي، لا Lorem Ipsum)

1. **مستقبل الذكاء الاصطناعي** — 10 شرائح، مخطط، جدول، أيقونات، ملاحظات متحدّث.
2. **Digital Marketing Strategy** — 8 شرائح EN مع جدول ميزانية ومخطط نمو.
3. **Startup Pitch Deck** — 10 شرائح بالترتيب الذي يتوقعه مستثمر.
4. **Education Presentation** — 8 شرائح FR/AR بأسلوب تعليمي مع اختبار قصير.

تُبذر تلقائيًا عند أول تشغيل (وفي الإعدادات زر «إعادة بذر العروض التجريبية»).

## النشر

- **م محليًا**: `npm run dev` (يُفتح على `:5173`)، أو `npm run build` ثم `npm run preview`.
- **على الإنترنت**: `.github/workflows/deploy-pages.yml` يبني (typecheck + vite build بـ `base=/KADMATI/`)
  وينشر على GitHub Pages عند أي دفع إلى `main`، مع `cp dist/index.html dist/404.html` لتعمل روابط
  `/edit/:id` العميقة (Pages لا يملك إعادة كتابة SPA). يلزم مرة واحدة فقط في إعدادات المستودع:
  **Settings → Pages → Source: GitHub Actions** — بدونه يفشل `actions/configure-pages` بخطأ «Pages not enabled».
- التطبيق يعمل بلا خادم وبلا مفاتيح: لا تسجيل دخول ولا API مطلوب. الصور تُخدَم من Google Fonts والباقي محلي.

## من PDF إلى عرض (Automatic Design)

مسار `/pdf`: ارفع ملف PDF فيُحلَّل محليًا داخل المتصفح (pdf.js + طبقة فهم خاصة) — عناوين، فقرات، قوائم، جداول، صور، هوية المستند — ثم يُبنى عرض **قابل للتعديل بالكامل** عبر نفس محرك القوالب (وليس صور صفحات). الملفات الممسوحة تدعم OCR عربي/إنجليزي/فرنسي عند الطلب.

التفاصيل الكاملة للبحث والمقارنات والتراخيص والمعمارية في [`PDF_ANALYSIS_RESEARCH.md`](./PDF_ANALYSIS_RESEARCH.md)، والاختبارات في `tests/pdf/` (`npm run test:pdf`).
